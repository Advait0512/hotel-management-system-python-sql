# 🏨 Hotel Management System (Python + MySQL)

## 📌 Overview
A hotel management system built using Python and MySQL to manage bookings, rooms, and customer data with efficient database operations.

## 🚀 Features
- Room booking system
- Customer management
- Room availability tracking
- CRUD operations on database
- Real-time status updates

## 🛠️ Tech Stack
- Python
- MySQL

## 📂 Project Structure
- `main.py` – Main application
- `database.sql` – Database schema
- `booking.py` – Booking logic

## ▶️ How to Run
1. Setup database using `database.sql`
2. Configure database connection
3. Run:
   ```bash
   python main.py
